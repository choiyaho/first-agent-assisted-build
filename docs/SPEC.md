## 0. 출발점 (주제 제안 원문)

> 소규모 카페 사장님이 메뉴 가격을 정할 때 쓰는 웹앱. 재료 원가, 판매가, 예상 판매량을 넣으면 마진과 손익분기점을 보여준다. 주변 카페는 "이 정도로 장사하니까"라는 감으로 가격을 정하는 경우가 많아서, 숫자를 근거로 판단할 수 있게 한다.
> - 기능 1: 메뉴별 원가·마진 계산
> - 기능 2: 월 고정비 기준 손익분기 판매량 계산
> - 기능 3: 가격·판매량 시나리오 비교

교수님 코멘트: 기능 구현은 간단하니 UI/UX 설계에 힘을 실을 것 → 계산은 가볍게, 화면 흐름과 읽기 쉬움에 집중한다.

## 2. 정의 결정

| ID | 결정 | 선택지 | 내 선택 | 이유 |
|---|---|---|---|---|
| D1 | 원가 입력 방식 | (a) 1잔 원가 직접 입력 (b) 재료 구매가·구매량 + 1잔 사용량으로 환산 | (a) 1잔 원가(재료+포장 합계) 직접 입력 | 처음엔 (b)를 골랐으나 일정과 교수님 코멘트(UI/UX 집중)로 범위를 줄임 |
| D2 | 1잔 변동원가에 넣을 것 | 재료 / 포장재 / 판매가 비례 비용(%) / 폐기·손실 | 재료+포장(1잔 원가 한 숫자) + 카드 수수료(%, 앱 전체 하나) | 수수료는 매 잔 붙는 실제 비용. 결제 방식 차이는 평균 비율을 넣어 반영 |
| D3 | 부가세 | (a) 판매가 ÷ 1.1(공급가)로 계산 (b) 무시하고 한계에 적음 | (a) 판매가는 부가세 포함가. 이익은 공급가 기준, 수수료는 판매가 기준. 일반과세자 가정 | 무시하면 1잔 이익이 약 9% 크게 나와 손익분기를 과소평가 |
| D4 | 마진 표기 | 1잔 이익(원) / 원가율 / 마진율 / 마크업 (용어 정의 포함) | 1잔 이익 = 판매가÷1.1 − 원가 − 판매가×수수료율. 원가율 = (원가 + 수수료) ÷ 판매가. 마진율 = 1잔 이익 ÷ 판매가 | 분모를 메뉴판 가격으로 해서 사장이 바로 이해. 원가율+마진율 = 90.9%(나머지는 부가세) |
| D5 | 손익분기 기준 | (a) 메뉴 하나 기준 (b) 판매 비중 가중 전체 잔 수 (c) 손익분기 매출액 | (b)+(c). 손익분기 잔 수 = 고정비 × Σ판매량 ÷ Σ(1잔 이익×판매량). 매출액(부가세 포함) = 고정비 × Σ(판매가×판매량) ÷ Σ(1잔 이익×판매량). 손해 메뉴도 합산하고 경고. Σ(1잔 이익×판매량) ≤ 0 또는 판매량 합 0이면 "손익분기 없음"과 이유 표시 | 메뉴가 여럿인 실제 카페에 맞음. 손해 메뉴를 빼면 손익분기를 과소평가 |
| D6 | 월 고정비 | 총액 하나 / 항목별 합계, 사장 본인 인건비 포함 여부 | 총액 하나. 입력 안내에 "사장 본인 인건비도 포함 권장" | 입력을 가볍게. 본인 인건비 누락 실수는 안내로 막음 |
| D7 | 시나리오 | 개수, 바꿀 수 있는 값. 판매량은 사용자 가정값 | 3개 고정: 지금 + A안 + B안. A안·B안은 전체 메뉴 판매가 변화(%)와 판매량 변화(%)를 슬라이더로 조정. 맨 위에 "가격을 바꾸면 한 달에 얼마나 남을까?"라는 질문, 각 안의 월 이익과 "지금보다" 차이를 카드로, 월 이익·손익분기 잔 수·매출액·고정비 회수율을 표로 나란히 비교. 각 안의 이름에 바꾼 비율을 적음(예: "A안 (가격 +10%, 판매량 -10%)") | 메뉴마다 고치는 것보다 조작이 쉽고 "가격 올리면 덜 팔려도 남나"에 바로 답함. 판매량만 같은 비율로 바꾸면 판매 비중이 그대로라 손익분기 잔 수는 변하지 않으므로, 판매량 변화의 효과는 회수율로 보여줌 |
| D8 | 단위·반올림 | 금액 단위, 비율 자릿수, 손익분기 잔 수 처리 | 계산은 분수(정확한 값)로 하고 화면 표시에서만 원 단위 반올림. 비율은 소수 1자리. 손익분기 잔 수·매출액은 올림 | 중간 반올림으로 1원·1잔 어긋나는 것을 막음. 내림하면 손실 구간 |
| D9 | 저장 | 저장 안 함 / CSV 내보내기·불러오기 | 저장 안 함. 앱을 열면 가상 예시 메뉴가 채워져 있음 | 범위 축소. 예시 데이터로 시연이 쉬움 |
| D10 | 화면 구성 | (a) 편집 표 하나 (b) 대시보드 + 카드 그리드 | (b) 맨 위 왼쪽 대시보드(월 이익, 손익분기 잔 수·매출액, 고정비 회수율, 손해 메뉴 수를 한 줄에 하나씩) + 오른쪽 「월 판매 계획」 펼치기(판매량 수정. 처음부터 펼쳐 있고 제목에 총 판매량. 좁은 화면에서는 대시보드 아래) → 메뉴판 카드 그리드(메뉴 그림, 메뉴명·판매가·원가 수정, 1잔 이익·원가율·마진율·매출 비중 표시). 값마다 고치는 곳은 한 군데 | 교수님 코멘트(UI/UX). 결과를 먼저 보고, 메뉴판처럼 읽힘. 판매량을 고치면 바로 옆 숫자가 바뀜 |
| D11 | 메뉴 카드 정렬 | 기준 목록, 동점 처리, 다시 정렬하는 때 | 정렬 기준: 매출 비중(기본)·마진율·1잔 이익·판매가·입력 순서, 모두 높은 순(입력 순서는 먼저 넣은 순). 매출 = 판매가(부가세 포함) × 월 판매량. 고른 기준의 값이 같으면 마진율 높은 순, 그것도 같으면 입력 순서(menu.csv 순서, 새 메뉴는 그 뒤). 순서는 앱을 처음 열 때, 정렬 기준을 바꿀 때, [다시 정렬]을 누를 때만 다시 계산. 값을 고치거나 메뉴를 추가해도 다른 카드 순서는 그대로(추가한 메뉴는 맨 뒤, 삭제한 메뉴는 그 자리에서 빠짐). 총매출이 0이면 비중은 "-", 순서는 마진율 → 입력 순서. 비중 합계는 보여주지 않고 도움말에 "반올림 때문에 합이 100%가 아닐 수 있음" | 고치던 카드가 다른 자리로 튀지 않게. 선택 칸은 같은 값을 다시 고르면 반응하지 않아 [다시 정렬] 버튼을 둠 |
| D12 | 고정비 회수율 | 표시 여부, 0 이하 처리 | 회수율 = Σ(1잔 이익×월 판매량) ÷ 월 고정비, 소수 1자리 %. Σ ≤ 0이면 "손익분기 없음". 고정비는 1원 이상이라(D15) 0으로 나누지 않음 | 100% 이상이면 흑자라 한눈에 읽힘. 예상 총 판매량 ÷ 손익분기 잔 수(올림 전)와 같은 값이라 중간 반올림이 없음(D8) |
| D13 | 손해 메뉴 | 기준(< 0 / ≤ 0), 예시 데이터 포함 여부 | 1잔 이익 ≤ 0원(0원 포함). 카드에 손해 표시와 "1잔을 팔아도 남는 돈이 없습니다 (0원 이하)" 경고, 대시보드에 손해 메뉴 수. 예시 데이터(menu.csv)에는 넣지 않고, 시연은 E1 디저트를 직접 추가 | 0원 메뉴는 고정비를 하나도 메우지 못함. 예시는 정상 가게처럼 보이게 |
| D14 | 배포 | 로컬 실행만 / Streamlit Community Cloud | Community Cloud(무료). main 브랜치 `src/app.py`, Python 3.12, requirements.txt 버전 고정 | 채점자가 설치 없이 링크로 실행. 비용 없음, 코드 구조 그대로 |
| D15 | 입력 최솟값 | 칸마다 최솟값 | 판매가 1원 이상, 월 고정비 1원 이상, 1잔 원가·월 판매량 0 이상, 수수료율 0~100% | 판매가 0은 비율, 고정비 0은 회수율을 계산할 수 없어 입력 단계에서 막음 |
| D16 | 메뉴 추가·삭제 | 편집 표 / [+ 메뉴] 양식 + 카드 [삭제] | 메뉴판 위 [+ 메뉴]로 양식(메뉴명, 판매가, 1잔 원가, 월 판매량)을 열어 추가. 이름을 비우면 "(이름 없음)", 그림은 기본 컵. 카드마다 [삭제]. 메뉴를 모두 지우면 안내 문구만 보이고 [+ 메뉴]는 남음. 저장하지 않으므로(D9) 새로고침하면 예시로 돌아감 | 카드 그리드에는 표의 행 추가·삭제가 없음. 사장이 예시를 자기 메뉴로 바꾸는 데 필요 |

## 3. 범위

### 포함
- 사이드바: 월 고정비, 카드 수수료율 입력
- 대시보드: 월 이익, 손익분기 잔 수·매출액, 고정비 회수율, 손해 메뉴 수, "손익분기 없음" 이유 표시
- 「월 판매 계획」 펼치기: 메뉴별 예상 월 판매량
- 메뉴판 카드 그리드: 메뉴명·판매가·1잔 원가 수정, 1잔 이익·원가율·마진율·매출 비중, 손해 표시, 정렬·[다시 정렬], [+ 메뉴]·[삭제]
- 시나리오 지금·A안·B안 비교: 지금 대비 월 이익 차이 카드와 비교 표
- 용어 설명(도움말)
- Streamlit Community Cloud 배포

### 제외 (이번 Project 1에서 하지 않음)
- 재료 구매가·구매량 환산, 단위 변환
- 폐기·손실률, 결제 방식·배달 채널별 수수료, 간이과세
- 고정비 항목별 입력
- 시나리오 4개 이상, 메뉴별 시나리오 값 편집
- 수요 예측, 저장·CSV, 로그인
