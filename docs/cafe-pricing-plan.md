## 3. 계산 모델 (참고)

```text
p  : 판매가 (D3에 따라 부가세 포함가 그대로, 또는 공급가 p ÷ 1.1)
v  : 1잔 변동원가 (D1·D2)
CM : 1잔 공헌이익 = p − v
원가율 = v ÷ p                공헌이익률 = CM ÷ p
월 이익 = Σ(CM_i × q_i) − F    (q_i: 메뉴 i의 예상 월 판매량, F: 월 고정비)

손익분기 잔 수 (메뉴 하나)        = 올림(F ÷ CM)                 CM ≤ 0 이면 "손익분기 없음"
손익분기 총 잔 수 (판매 비중 가중) = 올림(F × Σq ÷ Σ(CM_i × q_i))
손익분기 매출액                   = F × Σ(p_i × q_i) ÷ Σ(CM_i × q_i)
```

**방법 설명용 예시** (부가세 무시. 실제 검증 사례는 SPEC에서 정한 정의로 직접 만든다)
- 아메리카노 4,000원, 원가 1,000원 → 1잔 이익 3,000원, 원가율 25.0%
- 고정비 6,400,000원 → 6,400,000 ÷ 3,000 = 2,133.3 → **올림 2,134잔**. 2,133잔이면 2,133 × 3,000 = 6,399,000원 → 1,000원 손실
- 라떼 5,000원, 원가 1,500원, 예상 판매 아메리카노 1,200잔·라떼 800잔 → 월 이익 3,600,000 + 2,800,000 − 6,400,000 = 0 → 손익분기 총 잔 수는 예상 총량 2,000잔과 같아야 한다(일관성 확인)
- 판매가 1,000원, 원가 1,200원 → 1잔 이익 −200원 → "손익분기 없음" (오류로 멈추면 안 됨)

**함정: 소수 계산 후 올림**
판매 비중을 소수(0.5, 0.333…)로 만들어 가중평균한 뒤 올림하면, 나누어떨어지는 경우에도 1잔이 더 나올 수 있다.
- 실측 예: 고정비 9,100,000원, 1잔 이익 2,900 / 3,100 / 3,300원, 예상 판매 300 / 200 / 100잔
- 정확한 값 3,000잔 → 소수 가중평균 후 올림하면 **3,001잔**
- 위 모델처럼 정수로 곱한 뒤 마지막에 한 번 나누면 피할 수 있다. 검증 사례에 넣을 만하다.

**점검**

## 6. 검증 계획

- **check_calc.py**: 기대값은 SPEC 5번 손 계산에서만 가져온다. `calc.py`를 실행해 나온 값을 기대값으로 쓰면 자기 답을 자기가 채점하는 꼴이 된다.
- **대표 사례 3개**: 메뉴 1개 / 메뉴 여러 개 / 시나리오 비교
- **경계·실패 사례 후보** (1개 이상 필수)
  - 판매가 ≤ 원가 → "손익분기 없음"
  - 판매량 0, 빈 입력, 음수 입력
  - 나누어떨어지는 손익분기 (올림 결과가 +1 되지 않는지, §3 함정)
- **일관성 확인**: 예상 판매량에서 이익이 0이면 손익분기 총 잔 수 = 예상 총량
- **화면 확인**: 같은 사례를 화면에 넣어 check 결과와 같은 값인지 스크린샷으로 남긴다

**점검**
